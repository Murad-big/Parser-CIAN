# Парсер карточек риелторов Циан

Скрипт получает список риелторов из каталога Циан, открывает их публичные карточки через Selenium и подготавливает выгрузку в CSV.

В записи входят имя, телефон и, если они указаны в карточке, электронная почта и ссылка на Telegram.

## Технологии

Python, Requests, Selenium и стандартный модуль `csv`.

## Подготовка

Нужны Python и Chrome. Зависимости:

```bash
python -m pip install requests selenium
```

Регионы и диапазон страниц заданы в `main()` файла `Parser_CIAN.py`. Выходной файл — `realtores.csv`.

## Состояние проекта

Это ранний скрипт под конкретную разметку сайта. Перед использованием нужно проверить доступность источника и обновить селекторы.

В текущей версии функция `realtor()` открывает выходной файл в режиме `w` при каждом обращении: это может стирать уже записанные строки. Запись следует исправить до полноценной выгрузки. После подготовки точка входа — `python Parser_CIAN.py`.

Используйте только данные, к которым у вас есть разрешённый доступ, и соблюдайте условия источника.
